Menggunakan Pagar (Metode Otomatis)

  1. Kelilingi area rumah atau tanah milikmu menggunakan Pagar (Fence) jenis apa saja. Pastikan semua ujung pagar tersambung rapat membentuk kotak tanpa terputus.
  2. Tempelkan sebuah papan tanda (Sign) di salah satu tiang pagar tersebut.
  3. Tulis teks [rp] pada baris pertama papan tanda, lalu tekan selesai. Papan akan otomatis memproses dan mengunci wilayah di dalam pagar.

Peraturan & Perintah Tambahan RedProtect:

  • /rp addmember [Nama] → Memberikan izin bangun/buka chest kepada teman.
  • /rp removemember [Nama] → Mencabut izin bangun milik teman.
  • /rp info → Melihat informasi pemilik dan batas wilayah klaim tempat kamu berdiri.
  • /rp flag → Membuka Menu Untuk Mengatur Permission
  • /rp delete → Menghapus klaim perlindungan tanah (jika ingin pindah lokasi).

Membuat Toko Sendiri

  • Arahkan pandangan ke blok Barrel lalu ketik /shop create.
  • Klik blok tersebut (Left/Right Click) atau gunakan /shop manage <id> untuk mulai mengatur.
  • Klik ikon Lime Dye untuk membuat trade baru.
  • Masukkan item yang ingin dijual ke kolom Kiri, dan harga item di kolom Kanan.
  • Klik Lime Dye lagi untuk menyimpan. Gunakan TNT untuk menghapus trade.

Fitur Pembeli

  • /shop shops → Lihat semua toko.
  • /shop find <item> → Cari barang.
  • /shop view <id> → Lihat isi toko.

Fitur Penjual

  • /shop list → Daftar tokomu.
  • /shop stock → Atur stok barang.
  • /shop sold → Cek penjualan.

*Gunakan /shop help di dalam game untuk melihat daftar lengkap perintah admin/penjual.

Ada beberapa kemungkinan umum yang menjadi penyebab masalah koneksi tersebut:

  1. Server Maintenance: Silakan cek indikator status ketersediaan server di halaman depan web untuk memastikan server sedang online.
  2. Kesalahan Port Bedrock: Pengguna HP sering lupa mengubah port bawaan. Pastikan kolom Port diisi angka 22816, bukan port default 19132.
  3. Masalah Jaringan: Server YTTA Menggunakan Hosting Berlokasi Jakarta. Pastikan kestabilan ping internet provider kamu aman sebelum bermain.
