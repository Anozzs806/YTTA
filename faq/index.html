Server YTTA saat ini berjalan di versi utama 1.20.1 - 1.20.4.

Berkat dukungan plugin ViaVersion dan ViaBackwards, kamu bisa bergabung menggunakan versi Minecraft apa pun (mulai dari versi lama hingga versi terbaru saat ini).

Catatan: Meskipun kamu bisa menggunakan versi berapapun, disarankan untuk selalu menggunakan versi terbaru agar fitur-fitur game terbaru tetap bisa dinikmati dengan lancar tanpa bug visual.

Server YTTA menggunakan plugin RedProtect untuk mengamankan bangunan. Perlindungan ini otomatis mengunci area dari dasar batuan paling bawah (*bedrock*) hingga batas langit tertinggi. Kamu bisa memilih salah satu dari 2 cara mudah di bawah ini:

Cara 1: Menggunakan Pagar (Metode Otomatis)

  1. Kelilingi area rumah atau tanah milikmu menggunakan Pagar (Fence) jenis apa saja. Pastikan semua ujung pagar tersambung rapat membentuk kotak tanpa terputus.
  2. Tempelkan sebuah papan tanda (Sign) di salah satu tiang pagar tersebut.
  3. Tulis teks [rp] pada baris pertama papan tanda, lalu tekan selesai. Papan akan otomatis memproses dan mengunci wilayah di dalam pagar.

Cara 2: Menggunakan Alat Seleksi (Wand)

  1. Ketik perintah /rp wand di kolom chat untuk mendapatkan alat penanda wilayah.
  2. Pergi ke sudut pojok kiri depan tanahmu, lalu Klik Kiri pada blok lantai tersebut.
  3. Pergi ke sudut pojok kanan belakang secara diagonal, lalu Klik Kanan pada blok lantai seberangnya.
  4. Kunci area tersebut dengan mengetik perintah chat: /rp claim [Nama_Klaim] (Contoh: /rp claim rumahku).

Peraturan & Perintah Tambahan RedProtect:

  • /rp addmember [Nama] → Memberikan izin bangun/buka chest kepada teman.
  • /rp removemember [Nama] → Mencabut izin bangun milik teman.
  • /rp info → Melihat informasi pemilik dan batas wilayah klaim tempat kamu berdiri.
  • /rp flag → Membuka Menu Untuk Mengatur Permission
  • /rp delete → Menghapus klaim perlindungan tanah (jika ingin pindah lokasi).

Ada beberapa kemungkinan umum yang menjadi penyebab masalah koneksi tersebut:

  1. Server Maintenance: Silakan cek indikator status ketersediaan server di halaman depan web untuk memastikan server sedang online.
  2. Kesalahan Port Bedrock: Pengguna HP sering lupa mengubah port bawaan. Pastikan kolom Port diisi angka 25830, bukan port default 19132.
  3. Masalah Jaringan: Server YTTA menggunakan infrastruktur hosting lokal Indonesia. Pastikan kestabilan ping internet provider kamu aman sebelum bermain.
